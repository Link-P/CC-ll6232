I chose rectangles, circles, lines.I wanted to create a sense of perspective in p5.js. Each time to click, the shapes gradually become larger. At first, the rectangle is small and positioned on the left side of the canvas. Each time to click, the rectangle moves to the right and become larger. Meanwhile, the four lines extending from the corners of the canvas also change. the endpoint of each line remains connected to one corner of the rectangle. I actually spent some time to calculate the four corner positions. there is also a shorter line starting from the center of the rectangle. each time to click, this line rotates around the center of the rectangle. In this step, I actually forgot how translate works. I thought that using one time transform in the draw would correctly affect all the following shapes, so when I clicked, the line and a circle disappeared. I later tried to add translate in each shape, and solve the problem. The circle always remains centered at the endpoint of the short line. the circle moves with the endpoint of the line when it rotates. And the circle gradually becomes larger after each click. And the background color gradually becomes lighter with each click.
