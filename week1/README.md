# Week 1 notes

Personally, I think code is like magic for people use to create many amazing digital worlds. I feel I could only see these worlds but could not help create them because of the knowledge gap between people without coding experience and programmers. By using many software tools, I realized that they work by following instructions written in code. When I use generative AI tools such as Suno, Nano Banana, and Marble, their results often surprise me. Code is the foundation of all these tools. This is why I think code is like magic. And after week 1, I do not think code is as difficult as I thought before. I realized that many historical buildings and artworks are created follow rules, proportions and algorithms.
